FAMILIAJK TV V2
================
PWA tipo Smart TV para ChromeOS Flex.

Incluye:
- Streaming: Netflix, Disney+, YouTube, Prime Video, Max
- Música/biblioteca: Spotify, YouTube Music, Plex, Google Photos
- TV chilena: TVN, Mega, Chilevisión y Canal 13 (sitios oficiales)
- Perfiles locales: Jorge, Keila, Familia, Invitado
- Clima mediante Open-Meteo + geolocalización del navegador
- Navegación con flechas, Enter, Esc/Backspace y Home
- Service Worker para cargar el launcher aun si la conexión está inestable

INSTALACIÓN RÁPIDA
1. Sube TODOS los archivos de esta carpeta a la raíz de tu hosting HTTPS o GitHub Pages.
2. Abre la URL desde Chrome en ChromeOS Flex.
3. Menú de Chrome > Instalar FamiliaJK TV.
4. Fija la aplicación al estante.
5. Abre cada plataforma una vez e inicia sesión.
6. Acepta ubicación si quieres ver el clima.

IMPORTANTE
- ChromeOS Flex usa las versiones web de los servicios, no APK Android.
- Algunos sitios pueden cambiar sus URLs de señal en vivo.
- Para un kiosco real con autoarranque administrado se requiere gestión ChromeOS; para uso doméstico, la PWA instalada es la opción simple.
